
# Tutedude Task 5 – Laundry Service Hero Section

## Project Overview
A simple laundry service landing page created using HTML and CSS. The page includes a navigation bar and a hero section with service information, a call-to-action button, and a laundry-related image.

## Features
- Navigation bar with logo, menu links, and username button
- Hero section with a two-line heading
- Separate heading colors using CSS
- Laundry service description
- Book a Service Today button
- Laundry image with styled layout

## Technologies Used
- HTML5
- CSS3

## Project Structure
- `index.html` – Contains the webpage structure
- `style.css` – Contains the styling and layout

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
